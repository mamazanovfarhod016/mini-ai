# Дневник исследований Mini AI

Цель: ИИ, который **понимает, учится мгновенно и рассуждает** — без градиентного обучения ядра. Знания = факты из текста;
мышление = правила, графы, счётчики, которые можно прочитать и объяснить. Речь (говорилка) — отдельно, градиентная.

Метрики (tools/bench.py): bAbI 11 задач (рассуждение в простом мире), мир 350 фактов (усвоение, 2–3 шага, после перезапуска),
SciQ 300 (школьные вопросы по учебнику — понимание формулировки), операторы (сравнить / да-нет / счёт).
Рост мышления (tools/exp61_growth.py, tools/school.py): становится ли умнее **от исправлений**, без правок кода.

### 2. Понимание формулировки (SciQ 0.19 → 0.50) — ead7b8a, 7b61839
Разбор промахов: ответ есть в тексте у 249 из 300, находила 59. Причины и правки:
- **Слова-пустышки** вопроса (term, type, kind, name, group, part…) считались обязательными → вес ~0, не обязательны. 0.19→0.29
- **Формы слов**: plants/plant, bodies/body, held/hold, -ing/-ed.
- **Отрывок предложения** (span): если читатель не разобрал предложение на факты, ответ = свободный кусок предложения,
  покрывающего ≥60 % веса слов вопроса, без слов вопроса, с самым редким словом. Это не «поиск на удачу»: термины обязательны.
- **Attention без градиента**: глаголы/связки (holds, made, cannot, humans, associated) — мягкие, факт может сказать то же
  другим словом; покрытие считается по терминам. 0.343→0.427. Тип ответа («what ANIMAL GROUP», «which BODY SYSTEM») — не слово
  для поиска, а описание ответа.
- **Слой диалога выбрасывал ответы**: «that» в «socket that houses…» принимался за местоимение, подставлялась прошлая сущность.
  Местоимение — только в коротких вопросах без придаточных. 0.427→0.497.
- **Порядок слов**: ответ — тот пробел предложения, у которого те же соседи, что у «what» в вопросе
  («use ___ to make ATP» → oxygen, не glucose).

### 3. Рост мышления от исправлений (growth.py) — 7b61839, 7ba77b8, 6ab2982
Идея: мышление должно расти от разговора так же, как знания. Без градиента, всё читаемо (growth.json):
- **Доверие** к способу думать × форма вопроса (попал/промахнулся). С переносом: точная форма → тип («what term _») →
  класс (definition / which-of / how-many / where / process / fill). Считается относительно обычной точности способа; <3 случаев — шум.
- **Смелость**: догадываться отрывком или молчать — по опыту «отрывок попадал», «молчание было ошибкой».
- **Где ответ** (slot-rules): для типа вопроса — ответ в X или Y факта какой связи. Принцип класса — если ≥4 типов согласны.
- **Выученное внимание**: из исправления — каких слов вопроса не было в предложении с ответом → слово «лишнее»; ≥3 раз и не
  редкий термин → мягкое для всех вопросов. Перенос по смыслу (objects≈things).
- **Позиция ответа**: начало / после «called» / после «is a» / конец — по классу вопроса.
- **Связки слов**: humidity → water vapor (из подтверждённых ответов).
- **Диагноз ошибки**: silent / wrong-piece / wrong-fact / no-sentence — доли по классу меняют порог смелости и арбитра.
- **Арбитр**: все способы думают всегда; счёт = уверенность × доверие + бонусы; **самопроверка** по типу ответа.
Диалог: «no, it's X» / «yes» / «how did you grow?».

**Честные цифры.** exp61 (150 с учителем → 150 без): холодный 0.480 → после роста 0.467 — нет роста на первом протоколе.
Абляция (опыт 2000 вопросов → свежие 300): без роста 0.520, с ростом **0.550** (+3 %); держат смелость/диагноз (+0.7) и связки
слов (+1.3); доверие мешало (−0.7, переделано). Школа (SciQ train, 11 679 вопросов с учителем): кривая по 500 —
0.53 / 0.57 / 0.52 / 0.51 / 0.52 / 0.47 / 0.54 / 0.55 — колеблется с трудностью вопросов, тренда вверх пока нет.
**Вывод:** рост от опыта есть, но мал; главный рост за день — от правок кода (понимание формулировки), не от опыта.

### 4. Глубокое рассуждение (deep.py) — 09c97d7, 7ba5334
cot.py умел 2–4 шага только по географии. deep.py — общий: граф из всех фактов (узел = сущность или именная группа внутри Y,
ребро = факт в обе стороны), луч до 7 шагов с откатом (ветвь, не приближающаяся к словам вопроса, отбрасывается).
Цель = тип ответа («what SUGAR», «which ORGANELLE»); ответ обязан быть этого типа по определению в памяти, сам тип — не ответ.
Глаголы вопроса ведут по рёбрам (pumps → pump). Подвопросы: «the gas that blood carries» решается первым, подставляется.
Определения: «what term means X» → узел, чьё be-ребро покрывает X. Мысли = реально использованные факты.
Примеры из 14 предложений: nucleus → DNA → nucleotides → deoxyribose (3 шага); ATP → mitochondria; heart → blood → oxygen;
«Which organ takes in the gas that blood carries?» → oxygen → lungs.
Читатель: фразовые глаголы (take in, give off, break down, turn into, make up) — «Lungs take in oxygen» раньше не читалось.
SciQ 0.497 → **0.53**, bAbI/мир без регрессий. Школа с deep: первые 500 — 0.548 против 0.520 без deep.

### Рассуждение о мире: bAbI 20 задач 0.59 → 0.998 (2f12d47)
8 задач были на нуле — все про состояние мира во времени. rules.World: предметы едут с носителем и остаются, где
брошены (2, 3); события «дал/передал» (5); счёт в руках (7); местоимения he/she/they → последние действующие (11, 13);
карта «what is X east of» (4); «before the X» = последнее посещение (14); **мотивы выучиваются из чтения** —
счётчик «состояние → куда идут» (tired → bedroom, 20): 0 → 0.996 без единого правила про усталость.

### Нейронный глаз и читатель (exp2–exp3c)
Любым способом — значит и градиентные модели там, где правила слепы: формулировка.
- MiniLM (22M) — индекс предложений по смыслу, ленивый (кодируются только кандидаты). Вопрос ↔ верное предложение 0.85,
  неверное 0.26.
- DistilBERT-SQuAD (65M, 0.05 с/вопрос) — читатель: ядро выбирает 2–4 предложения-места, читатель достаёт кусок.
  Честные цифры A/B на SciQ 300: читатель как равный кандидат — 0.54 vs 0.52 без него, но выбран 73 раза и прав 35.
  Калибровка уверенности по измеренной точности (score<22 → 0.3–0.45) → 0.563, выбран 17, прав 4 — не вредит, но
  и почти не помогает сам. Урок: **обученный читатель слабее символьного отрывка на учебнике**, его место — второй
  свидетель (согласие с символьным кандидатом → уверенность вверх), не судья.
- Главный выигрыш блока — не нейросети, а **самопроверка по типу через граф** («what SUGAR» → ответ обязан быть
  определён как sugar; «contains dna» → штраф) и **перефраз, выученный из исправлений** (holds ↔ held, make ↔ produce).

### Самообъяснение
«why?» → реальный путь: способ, факты, что предлагали другие способы, уверенность. Исправление отвечает диагнозом
словами: «я нашла предложение, но взяла не тот кусок» / «я это знала, но не решилась» / «я этого не читала».
