## Рост сети — цель 100 млн параметров (решение Фарходa 18.10)
Путь: 9 млн (20 слоёв × 192, ночь 18→19.10) → ~30 млн → ~100 млн (например, 24 слоя × 576 или 20 × 640),
каждый раз через grow_params (знания переносятся). Растим, когда экзамены перестают расти на текущем размере.
Расчёт для 100 млн на Kaggle T4 (16 ГБ):
- память: веса + градиенты + Adam ≈ 1,6 ГБ (fp32) — помещается, обучение в mixed precision (fp16) + gradient checkpointing;
- тексты: хорошо бы ~2 млрд токенов (≈ 8 ГБ текста); минимум ~0,5 млрд. ГЛАВНОЕ УЗКОЕ МЕСТО — узбекский и русский
  простой текст: собрать FineWeb-2 / CulturaX (uz, ru), всю узбекскую Википедию, новости; английского хватает (TinyStories, FineWeb-Edu);
- время: ≈ 6·N·D = 1,2·10¹⁸ операций → ~15–25 ч видеокарты T4 → 1–2 недели бесплатной квоты (30 ч/нед), частями с чекпойнтами;
- телефон: 100 млн в 8 битах ≈ 100 МБ — нужен движок на C (см. выше), JS будет слишком медленным.
Задачи по пути:
- [ ] корпус 0,5–2 млрд токенов на 3 языках (сборка на Kaggle, не на сервере METTA)
- [ ] mixed precision + gradient checkpointing в torch_engine (тест: совпадает с fp32 в пределах допуска)
- [ ] обучение частями: продолжение с чекпойнта между сессиями Kaggle (12 ч лимит)
- [ ] сжатие 8/4 бит + движок на C для телефона
- 1–3 млрд параметров на бесплатном Kaggle нереально: ~16 ГБ только на веса+Adam (вся память T4), ~80 ГБ текста, ~70 дней видеокарты (расчёт 18.10).
