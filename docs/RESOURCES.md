## Как применять (порядок)
1. Сейчас: учебники по четвертям плюс увеличение объёма (уже работает).
2. Задачи со словами: gsm8k и gsm8k-ru. Брать по уровню четверти (короткие задачи раньше), экзамен на спрятанных.
3. Узбекский: перевод задач тем же способом, ответы проверяет Python.
4. Чтение: uz-books, TinyStories и fineweb-2 (uz/ru), когда модель вырастет (6 → 20 млн).
5. Учёба на ошибках: формат prm800k (шаг верен или неверен).
6. Самостоятельное рассуждение: метод TinyZero/R1 (награда за верный ответ, проверяет скрипт), начиная с 20 млн.
