# Char vs BPE — сравнение на одних и тех же вопросах

| | char | BPE |
|---|---|---|
| Тест-вопросы (не видела), намерение верно | 33.2% (107/322) | 95.0% (306/322) |
| Новые перефразировки (17 шт.), намерение верно | 35.3% (6/17) | 94.1% (16/17) |
| Словарь | 151 | 1000 |
| Контекст (block) | 224 | 117 |
| Шагов генерации на ответ | 49.5 | 24.4 |
| Скорость (сек на ответ, Python) | 64 мс | 21 мс |
| Размер файла | 986 КБ | 1196 КБ |

> **Честно о цифрах.** Строка «тест-вопросы» здесь НЕ равноправна: обе модели обучались,
> когда train/test-сплит зависел от `hash()` (случайный в каждом запуске, исправлено на crc32
> 18.10), поэтому часть этих «тестовых» вопросов модели видели при обучении.
> Честные held-out цифры — из логов самих прогонов: **BPE 83,9%** намерений (270/322,
> `docs/train_log_bpe.txt`), **char 32,3%** точных ответов (`docs/train_log_transformer.txt`).
> Полностью честная проверка — **перефразировки**: их нет в `data/intents.json` вообще.
> Ещё оговорка: char-модель — старый прогон (3000 шагов, без сбалансированного сэмплирования),
> BPE — 6000 шагов с ним; часть разницы — от этого, не только от токенизатора.
